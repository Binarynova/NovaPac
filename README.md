# Pac-Man-Emulator

Started Jan. 29, 2026

# First Launch
Emulator will ask you for a path to the directory where your ROMs are stored. This will be saved in a file in your emulator's directory.

# Supported ROMs
pacman, pacmanf, mspacman, mspacmnf, pacplus, matrix

# Controls:
## Menu:

| Keyboard    | Gamepad            | Function          |
|-------------|--------------------|-------------------|
| ESC         |                    | Close Emulator    |
| Cursor Keys | D-Pad / Left Stick | Menu Cursor       |
| Y           | Y Button           | Open / Close Menu |
| Enter       | A Button           | Select            |
| Tab         |                    | Open Options Menu |

## During Gameplay
| Keyboard    | Gamepad            | Function          |
|-------------|--------------------|-------------------|
| ESC         |                    | Close Emulator    |
| Cursor Keys | D-Pad / Left Stick | P1 Movement       |
| Y           | Y Button           | Open / Close Menu |
| C           | View Button        | P1 Coin           |
| Enter       | Menu Button        | P1 Start          |
